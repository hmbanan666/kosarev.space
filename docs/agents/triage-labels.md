# Triage labels

| Skill role | Tracker label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Needs maintainer evaluation |
| `needs-info` | `needs-info` | Waiting for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified for agent work |
| `ready-for-human` | `ready-for-human` | Requires human work |
| `wontfix` | `wontfix` | Will not be implemented |

When a skill names a triage role, use its tracker label from this table.
Readiness labels do not override repository approval boundaries.
